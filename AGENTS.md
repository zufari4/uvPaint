# Правила проекта

- При удалении файлов и папок не использовать флаг `-Force`.
- Перед рекурсивным удалением проверить абсолютные пути и убедиться, что они находятся внутри проекта.
- Сохранять готовое приложение `release/current/win-unpacked/` целиком, включая файлы окружения рядом с EXE.
- Не создавать дополнительные папки релизов: обновлять единственную сборку в `release/current/win-unpacked/`.
- Собирать распакованное приложение (`npm run dist`). Инсталлятор `release/current/uvPaint-Setup-<версия>.exe` собирается только для публикации релиза на GitHub (`npm run dist:installer`). Portable-упаковка и ZIP-архивы пока не нужны.
- Версия приложения — `1.0.2`, пока пользователь не попросит её изменить.
